# Soundtrack

The site ships a Matrix-flavoured soundtrack that is **synthesised in the browser**
— a sub-bass pulse, filtered noise for rain, and sparse detuned bells, generated by
the Web Audio API. It is the default because it works on a fresh clone with no
asset, no network and no licence question.

## Using a recording instead

If you have a licensed file you would rather hear — the film's score, a
commissioned track, a CC0 loop — this is a one-line change and not a refactor.

**1. Put the file in `public/audio/`.**

```
public/audio/soundtrack.ogg
```

**2. Name it:**

```bash
# .env.local
SOUNDTRACK_FILE=soundtrack.ogg
```

That is the whole thing. There is no build step and no import.

### What is accepted

| Form | Result |
|---|---|
| `soundtrack.ogg` | resolved to `/audio/soundtrack.ogg` |
| `/assets/theme.mp3` | used as given |
| `intro.no-loop.mp3` | plays once instead of looping |
| `soundtrack.txt` | **ignored**, the synth plays |
| unset | the synth plays |

Extensions: `.ogg` `.oga` `.mp3` `.m4a` `.mp4` `.wav` `.flac` `.aac` `.opus`.
A value with no audio extension is treated as a typo rather than guessed at — a
request for a file that does not exist is an error the reader cannot act on.

**Prefer `.ogg`.** It is the only one that loops a full-length track on every
browser this site supports, and a Vorbis loop is smaller than the same audio as
AAC.

## What it will not do

It will not download anything, and it cannot be pointed at a remote host. A port
that fetched a recording would be a hard dependency on somebody else's uptime and
on their CORS policy, for background audio on a résumé.

If the file is named but fails to decode, the synth plays instead and the button
keeps working. The reader asked for music, and the synth is music.

## Why it is off by default

Every browser blocks autoplay with sound, and that is the correct outcome rather
than a limitation to work around. Sound on a portfolio is an interruption, not an
enhancement. The control is in the header, muted until pressed, and the choice is
remembered — an unreadable or stale preference resolves to silence, because the
failure mode of guessing wrong is a site that makes noise at someone who never
asked.
